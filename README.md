# 모빌리티 브리프

모빌리티 산업(자율주행·UAM·전기차·배터리·모빌리티 서비스·정책 규제) **뉴스 동향**을
매일 수집해 누적하는 개인용 데이터베이스 + 대시보드입니다.

## 대시보드

**https://claude.ai/code/artifact/688798f0-9f72-4476-b4f9-119c130b689a**

어느 기기에서든 이 링크로 최신 누적 기사 목록과 트렌드 차트를 볼 수 있습니다. 갱신 후에도
같은 링크로 재배포되므로 URL은 바뀌지 않습니다.

## 구성

| 경로 | 역할 |
|---|---|
| `data/mobility_news.json` | 누적 DB. 기사 항목(제목·요약·URL·날짜)을 append-only로 저장 |
| `data/schema.md` | 스키마 및 작성 규칙 |
| `scripts/generate_dashboard.py` | DB → `artifact/dashboard.html` 생성기 (로컬 수동 실행용) |
| `artifact/dashboard.html` | 생성된 대시보드 (Claude Artifact로 발행) |
| `docs/DAILY_BRIEFING_PLAYBOOK.md` | 자동 실행 세션이 따르는 절차 (아래 "자동화 현황" 참고) |

## 데이터 모델

각 기사는 제목·1~2문장 요약·URL·날짜·출처·카테고리·지역을 저장합니다.

- **카테고리**: 자율주행 | UAM | 전기차·배터리 | 모빌리티 서비스 | 정책·규제 | 기타
- **지역**: 국내 | 글로벌
- 대시보드는 이 누적 데이터를 월간/분기별/반기별로 묶어 트렌드 차트로 보여주고,
  전체 목록은 최근 수집순으로 검색·필터링할 수 있습니다.

## 수동 실행

```bash
# 대시보드 재생성 (DB를 직접 편집한 뒤)
python3 scripts/generate_dashboard.py
```

## 자동화 현황

이 저장소는 `docs/DAILY_BRIEFING_PLAYBOOK.md`에 정의된 절차(GitHub API 도구 +
WebSearch + Artifact 재배포, Bash 미사용)로 매일 자동 수집하도록 설계되었습니다.

**다만 현재 자동 실행 Routine은 비활성 상태입니다.** 이 저장소가 원래 있던
`toughengine/TEST1`에서 약 4일간 실제 운영한 결과, 이 실행 환경의 `WebSearch`는
최신순이 아니라 관련도순으로 결과를 정렬하고 대부분의 언론사 도메인에 대한 직접
접근(`WebFetch`)이 차단되어 있어, "발행일 1~2일 이내"라는 엄격한 신선도 기준을
꾸준히 만족시키지 못했습니다 (검증 결과 최상의 경우도 3~6일 전 기사 수준). 이는
검색 프롬프트의 문제가 아니라 이 클라우드 세션의 네트워크/검색 도구 자체의 구조적
한계로 확인되어, 사용자 판단으로 자동화를 중단했습니다.

현재 DB의 15건은 그 운영 기간 동안 실제로 수집된 기사입니다. 대시보드는 이 15건
기준으로 정적으로 발행되어 있으며, 새 기사를 추가하려면 위 "수동 실행" 절차로 DB를
직접 편집한 뒤 재생성하거나, 자동화를 다시 활성화해야 합니다.

## 연혁

이 저장소는 한때 `toughengine/mobility-policy-radar`라는 이름으로 "모빌리티
정책·사업 브리프"(정부 정책/신규사업 추적 + 분석) 컨셉으로 운영된 적이 있습니다.
사용자 요청에 따라 원래의 뉴스 동향 브리핑 컨셉으로 되돌렸습니다. 정책·사업 버전의
데이터(`policy_items.json`, 14건)와 문서는 이 되돌리기 시점 이전 git 히스토리에
남아 있습니다. 대시보드 아티팩트 URL은 그대로 이어받았습니다.
