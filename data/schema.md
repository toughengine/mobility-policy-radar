# `mobility_news.json` 스키마

모빌리티 동향 브리핑의 누적 DB 파일입니다. `scripts/generate_dashboard.py`가 이 파일을
읽어 대시보드를 생성합니다. **매일 자동화 작업은 이 파일에 새 기사를 append 하는 방식으로
동작합니다** — 기존 항목은 절대 수정/삭제하지 않습니다 (오탈자 수정 등 예외 제외).

```json
{
  "$schema": "mobility_news.schema.v1",
  "updated_at": "ISO8601 타임스탬프 (마지막 갱신 시각)",
  "articles": [
    {
      "id": "날짜-슬러그 형태의 고유 ID, 예: 2026-08-19-weride-uber-dubai",
      "date": "기사 발행일 YYYY-MM-DD (URL/본문에서 확인)",
      "date_estimated": "true면 발행일을 정확히 확인 못해 수집일로 대체했다는 표시",
      "collected_at": "이 브리핑 파이프라인이 수집한 날짜 YYYY-MM-DD",
      "title": "기사 제목 (원문 그대로 또는 자연스러운 한국어 제목)",
      "summary": "1~2문장 한국어 요약 (핵심 사실 위주, 과장/추측 금지)",
      "url": "기사 원문 URL (중복 판단 기준 키)",
      "source": "매체명",
      "category": "자율주행 | UAM | 전기차·배터리 | 모빌리티 서비스 | 정책·규제 | 기타",
      "region": "국내 | 글로벌"
    }
  ]
}
```

## 규칙

- **중복 방지**: `url`이 이미 존재하면 추가하지 않는다 (같은 사건의 다른 매체 보도는 더 대표성
  있는 쪽 1건만 채택하거나, 제목에 매체명을 병기해 둘 다 추가할 수 있다).
- **카테고리는 위 6개 값 중 하나만** 사용한다 (대시보드 색상/집계가 고정된 순서에 의존함).
- **날짜를 알 수 없으면** 수집일로 채우고 `date_estimated: true`로 표시한다 (대시보드에
  "추정" 배지로 표기됨).
- **요약은 과장 없이 사실 위주 1~2문장**. 광고성 문구, 추측성 전망 단정은 피한다.
- 새 항목은 배열 어디에 추가해도 무방하다 (대시보드가 날짜 기준으로 정렬한다).
